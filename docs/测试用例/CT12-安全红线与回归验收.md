# CT12 安全红线与回归验收

## 目标

确认交付物不泄露凭据、真实表名或密态明文，并完成自动化回归。

## 步骤

1. 扫描前端和文档中的客户真实表名、真实规模、密码、Token、签名。
2. 查询数据库：

```sql
SELECT count(*) FROM security_data_sources WHERE security_config_json::text ~* 'password';
SELECT count(*) FROM security_confidential_tasks WHERE execution_summary_json::text ~* 'values|plaintext';
```

3. 执行：

```bash
docker compose --env-file docker/.env -f docker/docker-compose.yml exec -T security-runtime \
  pytest -q tests/test_runtime_authorization.py tests/test_runtime_homomorphic.py \
  tests/test_runtime_measurement_archive.py tests/test_runtime_publish.py \
  tests/test_runtime_streaming.py
npm run typecheck
git diff --check
```

## 预期

扫描结果为 0；后端回归全部通过；前端类型检查和差异检查通过。任何失败都必须记录为阻塞，不得用全量种子或伪造数据掩盖。
