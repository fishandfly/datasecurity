# TC03 接入校验与完整性

## 1. 用例信息

| 项目 | 内容 |
| --- | --- |
| 用例编号 | TC03 |
| 用例名称 | 资源级接入校验与完整性检查 |
| 验证目标 | 验证资源级校验规则（必填字段/数值范围/重复键）、未关联量测容错、接入批次日志与完整性拦截形成真实闭环 |
| 对应需求 | 研究内容 1"在数据接入过程中进行完整性检查，防止数据被篡改或泄露"；预期目标"轻量校验与加密程序" |
| 优先级 | 高 |
| 执行角色 | 数据管理员 |
| 测试入口 | 数据资源详情 → 接入规则 tab |

## 用户故事

> 作为数据管理员，我希望在数据进入安全管控前先按客户量测口径校验完整性，并对无法关联设备档案的量测做容错处理，避免脏数据进入授权链路。

## 2. 验收范围

1. 16 个资源均具备资源级接入校验规则（`inheritSourceRules=false`）。
2. 校验规则覆盖必填字段、数值范围、重复键。
3. 未关联量测归档（`GRID-NO-RELAD-009`）无校验规则时允许告警不阻断（容错）。
4. 接入抽样可读取真实物理表数据。
5. 校验拦截形成可查询批次日志。

## 3. 前置条件

- 已完成 TC01。
- 已登录 `nocobase`。

## 4. 操作步骤

### 步骤 1：查看资源接入规则

打开 `http://localhost:5173/data-catalog/security-governance/resources`，进入"低频电压曲线"详情 → "接入规则" tab。

预期：展示规则：

| 项 | 值 |
| --- | --- |
| 必填字段 | `DATA_TIME, REGION_CODE, PSR_ID, MEASURE_TYPE, VOLTAGE, QUALITY_CODE` |
| 数值范围 | `VOLTAGE: [0, 1000]`（kV） |
| 重复键 | `DATA_TIME + PSR_ID + MEASURE_TYPE` |
| 继承源规则 | 关闭（`inheritSourceRules=false`） |

### 步骤 2：核对资源级规则落库

```bash
docker exec nocobase-8196-postgres-1 psql -U nocobase -d nocobase -c \
  "SELECT resource_code, stat_base->'ingest_validation'->>'requiredFields' AS required_fields, \
          stat_base->'ingest_validation'->>'numericRanges' AS ranges \
   FROM eco_data_resources WHERE resource_code IN ('GRID-LVF-VOLT-001','CUST-DAILY-ENERGY-003','GRID-LVF-PF-006')"
```

预期：低频电压含 `VOLTAGE` 范围；日冻结含 `PAP_R` 范围；功率因数含 `POWER_FACTOR: [0,1]`。

### 步骤 3：未关联容错检查

1. 打开"未关联量测归档"（`GRID-NO-RELAD-009`）详情 → 接入规则。
2. 预期：资源级规则存在（必填 `DATA_TIME/MEASURE_TYPE/VALUE/QUALITY_CODE`），但允许告警不阻断（与客户 `*_NO_RELAD` 表口径一致）。

### 步骤 4：接入抽样读取真实数据

在资源详情页点击"接入抽样"（或预览最新行）。

预期：低频电压返回最近真实行，字段为业务名称（如"采集时间/设备档案标识/电压"），设备标识脱敏显示（`PSR***`）。

### 步骤 5：核对接入批次日志

```bash
docker exec nocobase-8196-postgres-1 psql -U nocobase -d nocobase -c \
  "SELECT batch_code, status, source_id, \"createdAt\" FROM security_ingest_logs ORDER BY \"createdAt\" DESC LIMIT 8"
```

预期：存在真实批次，且可区分通过/拒绝（如 `INGEST-...` 通过 10 条；`INGEST-ERROR-...` 通过 0 条拒绝 1 条）。

## 5. 通过标准

- 抽样资源校验规则与客户量测口径一致（电压 0~1000kV、功率因数 0~1、电流/功率范围）。
- 未关联资源容错不阻断。
- 接入抽样读取真实物理表且标识脱敏。
- 批次日志可查询且通过/拒绝可区分。
