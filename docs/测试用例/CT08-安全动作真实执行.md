# CT08 安全动作真实执行

## 目标

验证安全动作产生实际输出，不只是记录动作名称。

## 步骤

1. 低频电压 API：检查 `PSR_ID` 等标识字段为脱敏值，`meta.outputMode=masked`。
2. L1 区域负荷 API：检查只返回小时、统计值和样本数，`outputMode=aggregate`。
3. 日冻结 `PAP_R`：检查 BFV `sum` 结果摘要。
4. 客户曲线 `VALUE`：检查 CKKS `mean` 结果摘要。
5. 使用 `APP-EXTERNAL-C` 和场景 `cross-domain-encrypted` 重复日冻结 BFV，验证跨域主体只能获得密态摘要。
6. 查询 `security_confidential_tasks.execution_summary_json`。

## 预期

BFV `verificationPassed=true` 且 `absoluteError=0`；CKKS 误差小于 `tolerance`；内部和跨域密态任务均为 `completed` 且 `sample_count>0`。响应、任务摘要和审计摘要均不得包含 `values` 或 `plaintext` 数值数组。
