# CT05 主体鉴权与动态策略配置

## 目标

验证主体凭据、API 授权清单及动态策略多因素配置。

## 步骤

1. 查询三主体的 `subject_status`、`credential_ref`、`allowed_api_codes_json`。
2. 查询策略：

```sql
SELECT p.policy_code,s.subject_code,a.api_code,p.scenario,p.output_mode,
       p.source_ips_json,p.allowed_time_ranges_json,p.max_query_days,p.max_rows,
       p.region_scope_json,p.abnormal_access_rules_json,p.publish_status
FROM eco_resource_security_policies p
JOIN security_access_subjects s ON s.id=p.subject_id
JOIN security_api_resources a ON a.id=p.api_resource_id
ORDER BY p.id;
```

3. 用各主体环境变量执行一个合法 HMAC 请求；再用错误密钥和错误场景各执行一次。

## 预期

正确请求按主体、API、场景命中唯一已发布策略；错误密钥返回 `401 SIGNATURE_INVALID`，错误场景返回 `403 POLICY_NOT_FOUND`。策略包含时间、区域、行数和行为规则，凭据均为引用。
