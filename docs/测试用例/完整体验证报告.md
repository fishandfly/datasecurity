## 5. 审计与风险事件

`security_policy_decision_logs.applied_limits_json` 顶层已核验包含：

```text
labelEnrichment / classification / dynamicPolicy / securityActions / hardConstraints / runtimeTrace
```

本轮新增核验：`labelEnrichment.fieldTags` 展示字段级补全位置；标签补全结果在日志中心和资源详情中按“分类组 -> 标签项”嵌套缩进显示，分类组与标签项通过二级缩进和层级线区分；`policyEvaluations` 展示候选策略及运行规则逐条结果和原因；`accessPath` 展示数据源 -> 数据资源 -> 数据应用 -> API -> 输出路径。日志中心筛选器已覆盖数据源、数据应用、数据资源，旧分散日志表未再读取。

风险事件通过 `decision_log_id` 关联决策日志，`action_taken=deny`。通知、消息推送、工单和人工处置不属于本次验证范围。
