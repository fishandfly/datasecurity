# CT11 运行监控与流式空态

## 目标

验证拒绝访问可从完整版日志追溯、页面可观测，且流式无数据时正常降级。

## 步骤

1. 执行一次已知拒绝请求，查询对应 `riskFactors`、`dynamicPolicy`、`securityActions` 和 `runtimeTrace`。
2. 登录首页切换“实时运行情况”“分层策略流转”“同态加密流转”。
3. 打开日志中心，检查按数据源、数据应用、数据资源三类筛选。
4. 查询流式三表：

```sql
SELECT (SELECT count(*) FROM security_streaming_events),
       (SELECT count(*) FROM security_streaming_windows),
       (SELECT count(*) FROM security_streaming_runs);
```

## 预期

拒绝原因、策略评估和安全动作可在完整版日志追溯；页面指标来自真实接口；流式保持 `0/0/0` 时显示空态，不显示虚构批次且不返回 400/500。
