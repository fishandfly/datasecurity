# CT03 资源、字段、分类与标签配置

## 目标

验证资源档案、字段安全档案、分类分级和标签目录完整。

## 步骤

1. 查询 `eco_data_resources` 的资源编码、层级、关联状态。
2. 按资源统计 `eco_resource_security_fields`，核对字段分类、安全等级、重要字段和脱敏要求。
3. 核对日冻结字段至少包含 `DATA_DATE`、`CONS_NO`、`PAP_R`，低频电压字段包含 `PSR_ID`、`VOLTAGE`。
4. 在分类标签页确认“全部标签 10”。

## 预期

5 个资源均为 `enabled/linked`，字段安全档案共 50 条；防护层为 L1=1、L2=2、L3=2；标识字段（如 `CONS_NO`、`PSR_ID`）被标记为需脱敏，标签总数为 10。
