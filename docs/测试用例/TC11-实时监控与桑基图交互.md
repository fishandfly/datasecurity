# TC11 实时监控与桑基图交互

## 1. 用例信息

| 项目 | 内容 |
| --- | --- |
| 用例编号 | TC11 |
| 用例名称 | 实时监控页面与分层策略流转桑基图 |
| 验证目标 | 验证首页"数据安全运行链路 + 实时运行监控三 tab"、桑基图链路、节点跳转、连线明细与实时窗口 |
| 对应需求 | 3.1 新增实时监控能力（安全接入/分层策略/同态加密可视化） |
| 优先级 | 高 |
| 执行角色 | 系统管理员 / 验收人员 |
| 测试入口 | `http://localhost:5173/data-catalog/`（首页） |

## 用户故事

> 作为验收人员，我希望在一屏看到"数据源 → 接入 → 分层 → 输出 → 应用"的完整运行链路，并能点击任意节点/连线查看真实详情，确认监控不是静态示意图。

## 2. 验收范围

1. 首页顶部"数据安全运行链路"，下方"实时运行监控"三 tab（实时运行情况 / 分层策略流转 / 同态加密流转）。
2. 分层策略流转链路完整：10 数据源 → 4 接入通道 → 16 资源 → l1/l2/l3 防护层 → 4 输出模式 → 21 数据应用。
3. 节点点击：数据源/资源/应用跳转详情页；通道/防护层/输出节点在下方明细面板展示记录。
4. 连线点击显示真实接入日志或调用与决策日志。
5. 实时运行情况 tab 的事件流与异常分析来自真实数据。
6. 同态加密流转 tab 展示资源 → 算法 → 操作 → 状态 → 校验链路。

## 3. 前置条件

- 已完成 TC01-TC10。
- 已登录 `nocobase`。

## 4. 操作步骤

### 步骤 1：首页结构与链路检查

1. 打开首页。
2. 确认顶部为"数据安全运行链路"（量测数据 → 中台统一供给 → 安全传输 → 完整性校验 → 分类分级 → 数据档案 → 安全策略 → 同态加密 → 访问策略 → 跨域访问应用）。
3. 确认其下为"实时运行监控"三 tab。

### 步骤 2：分层策略流转链路核对

1. 点击"分层策略流转"tab。
2. 核对链路描述：`数据源（源端系统）→ 接入通道 → 数据资源 → 数据中台资源防护层 → 数据服务输出模式 → 数据应用`。
3. 核对节点列：
   - 数据源 10 个（含"新一代集控站量测数据源""网格化气象预测量测数据源"）
   - 接入通道 4 类（数据库直连 / 已有 API / E 文件通道 / 消息服务通道）
   - 数据资源 16 个（含低频日电压相位角曲线、高压日用能信息、低压日用能信息、高压日负荷）
   - 防护层 l1 仅聚合 / l2 明细受控 / l3 仅密态
   - 输出模式 明细/聚合/密态/脱敏
   - 数据应用 21 个

### 步骤 3：节点跳转

1. 点击数据源节点（如"用采2.0量测数据源"），预期跳转数据源页。
2. 返回首页，点击资源节点（如"高压日用能信息"），预期跳转资源详情（分类=电量类、字段数 15、访问策略 2 条）。
3. 返回首页，点击应用节点（如"网上电网应用"），预期跳转数据应用/主体页。

### 步骤 4：节点明细联动

1. 点击防护层节点"l2 明细受控"，预期下方明细面板显示"防护层资源明细"（含该层资源与基准物理表）。
2. 点击输出模式节点"密态输出"，预期显示"输出模式访问策略明细"（24 条级，含营销 2.0、售电量预测、充换电等密态策略）。

### 步骤 5：连线明细联动

1. 鼠标悬停任意一条连线，预期该线突出显示（变亮、加粗，透明度由 0.32 提升到 0.95、线宽增加约 4px），提示可点击。
1. 点击"聚合输出 → 新能源选址及配网承载力应用"连线，预期明细面板显示"调用与决策日志"，包含真实请求（requestId、时间、应用、API、决策、风险级别、输出模式、返回行数）。
2. 点击"数据源 → 接入通道"连线，预期显示接入校验日志。

### 步骤 6：实时运行情况 tab

1. 点击"实时运行情况"tab。
2. 核对卡片计数：实时接入、资源与 API、访问决策、风险待办、密态任务。
3. 核对"实时安全事件流"：事件来自真实日志（接入校验/访问决策/同态任务），含时间、类型、来源应用、风险等级。
4. 核对"访问异常分析"来自真实风险数据。

### 步骤 7：同态加密流转 tab

1. 点击"同态加密流转"tab。
2. 核对链路：数据资源 → 算法（整数精确型/浮点近似型） → 计算操作（求和/平均值） → 任务状态 → 结果校验。
3. 点击节点，明细面板显示同态任务明细（含最近真实完成的 BFV/CKKS 任务）。

## 5. 通过标准

- 首页结构与三 tab 正常。
- 桑基图六列节点数量与基线一致（10/4/16/3/4/21）。
- 数据源/资源/应用节点可跳转；通道/防护层/输出节点明细联动。
- 连线点击显示真实接入日志与调用决策日志。
- 事件流、异常分析、同态任务均来自真实数据。
