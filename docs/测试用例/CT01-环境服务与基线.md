# CT01 环境、服务与小样本基线

## 目标

确认服务可用，当前环境没有被全量种子污染。

## 步骤

1. 执行 README 中的 `docker compose ps`、运行服务和 OpenFHE 健康检查。
2. 查询基线：

```sql
SELECT 'sources',count(*) FROM security_data_sources WHERE connection_status <> 'disabled'
UNION ALL SELECT 'resources',count(*) FROM eco_data_resources WHERE resource_status='enabled'
UNION ALL SELECT 'apis',count(*) FROM security_api_resources WHERE api_status='enabled'
UNION ALL SELECT 'subjects',count(*) FROM security_access_subjects WHERE subject_status='enabled'
UNION ALL SELECT 'policies',count(*) FROM eco_resource_security_policies WHERE policy_kind='access_policy' AND policy_status='enabled';
```

## 预期

健康状态为 `ok`；当前启用数量依次为 `1/5/5/3/10`，API 总记录数为 6（另有 1 条草稿）。前端首页显示真实计数，不要求全量演示数量。
