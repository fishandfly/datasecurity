# CT06 标签补全与分类分级执行

## 目标

验证调用方不提交标签时，执行引擎仍自动补全标签并按 L1/L2/L3 选择安全边界。

## 步骤

1. 以 `APP-INTERNAL-A` 调用低频电压脱敏 API。
2. 以 `APP-INTERNAL-A` 调用 L1 区域负荷聚合 API `region-load-query`。
3. 以 `APP-INTERNAL-B` 调用日冻结 BFV 密态 API。
4. 用各请求编号查询 `applied_limits_json`。

## 预期

- L2 审计含资源/字段标签、`classification.protectionLevel=l2`、`ISOLATE_L2`、`MASK`。
- L1 只返回聚合，含 `ISOLATE_L1`、`ROUTE_TO_ISOLATION`，无明细标识。
- L3 审计含 `ISOLATE_L3`、`ROUTE_TO_HE_COMPUTE`，调用方无需传入标签参数。
- 每条日志均含五阶段 `runtimeTrace`，顺序固定为标签补全、分类分级、动态策略、安全动作执行、审计记录。
