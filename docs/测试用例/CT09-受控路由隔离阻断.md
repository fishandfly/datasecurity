# CT09 不可执行受控路由阻断

## 目标

验证直连路由无法执行脱敏、聚合或密态动作时，不会原样转发受控数据。

## 步骤

1. 执行单测：

```bash
docker compose --env-file docker/.env -f docker/docker-compose.yml exec -T security-runtime \
  pytest -q tests/test_runtime_authorization.py -k direct_api_isolated
```

2. 如需接口级验证，在事务中准备 `access_mode=direct`、`output_mode=masked` 的临时 API/策略并调用，结束后回滚。
3. 查询该请求的决策日志。

## 预期

返回 `403 TAG_CONSTRAINT_VIOLATION`，`riskFactors` 含 `directRouteIsolation`，动作链以 `DENY` 结束，风险分 90，并留下完整拒绝审计日志。不得访问上游或返回原始数据。
