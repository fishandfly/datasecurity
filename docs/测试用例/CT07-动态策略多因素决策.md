# CT07 动态策略多因素决策

## 目标

验证主体、API、场景、时间、区域和行数共同参与决策。

## 步骤

以低频电压 API 为对象，分别执行：

1. 合法主体、场景、区域和 `pageSize=3`。
2. 仅修改场景为 `unmatched-new-engine`。
3. 请求超过策略允许天数的时间范围。
4. 请求 `pageSize=10000`。
5. 请求 `regionCode=REGION-Z`。

## 预期

合法请求 `200 allow`；其余依次返回 `POLICY_NOT_FOUND`、`QUERY_RANGE_EXCEEDED`、`ROW_LIMIT_EXCEEDED`、`SCOPE_VIOLATION`。拒绝日志的 `riskFactors` 能说明具体原因，并保存命中的动态策略或策略缺失信息。
