# TC10 数据应用访问链路

## 1. 用例信息

| 项目 | 内容 |
| --- | --- |
| 用例编号 | TC10 |
| 用例名称 | 数据应用访问链路与真实调用日志 |
| 验证目标 | 验证 21 个数据应用（7 专业）通过授权策略消费数据资源，形成真实调用与决策日志，覆盖明细/脱敏/聚合/密态四类输出 |
| 对应需求 | 研究内容 3"为网上电网、数智吉电等 51 套应用提供数据支撑"；四视角"数据应用" |
| 优先级 | 高 |
| 执行角色 | 安全管理员 / 应用负责人 |
| 测试入口 | `http://localhost:5173/data-catalog/security-governance/access/subjects`；决策日志 |

## 用户故事

> 作为安全管理员，我希望每个业务应用（营销、设备、发展、安监等专业）都有明确的数据授权和真实调用记录，既能支撑业务，又能回答"谁在什么时间调了什么数据"。

## 2. 验收范围

1. 21 个应用齐全，覆盖客户 7 专业。
2. 每个应用授权多个资源/API，形成多对多链路。
3. 批量演示调用脚本可复现生成真实 allow 决策日志。
4. 四类输出模式（明细/脱敏/聚合/密态）均有真实调用。
5. 决策日志可查询应用/API/时间/结果。

## 3. 前置条件

- 已完成 TC01-TC09。
- `SUBJECT_DEMO_SECRET` 已配置；10 个有物理表资源 API 已发布。

## 4. 操作步骤

### 步骤 1：核对 21 应用与专业覆盖

```bash
docker exec nocobase-8196-postgres-1 psql -U nocobase -d nocobase -c \
  "SELECT subject_code, subject_name, organization_name FROM security_access_subjects ORDER BY id"
```

预期：3 个验收主体 + 18 个客户应用；组织覆盖 营销部/数字化部/设备管理部/发展部/安监部/纪委办公室/审计监管部/调控中心等 7 专业。

### 步骤 2：核对应用-资源授权关系

```bash
docker exec nocobase-8196-postgres-1 psql -U nocobase -d nocobase -c \
  "SELECT s.subject_code, count(p.id) AS policies FROM security_access_subjects s \
   JOIN eco_resource_security_policies p ON p.subject_id = s.id AND p.policy_kind='access_policy' \
   GROUP BY s.subject_code ORDER BY policies DESC LIMIT 10"
```

预期：客户应用均有多条访问策略（如网上电网 4 条：低频电压/电流/功率/相位角；营销 2.0 4 条：日冻结/电能示值曲线/高压日用能/低压日用能）。

### 步骤 3：批量生成真实调用

```bash
cd /Users/fish/Documents/FishStudio/AI/2026/012-电网安全-v2.0
node scripts/generate-customer-calls.mjs
```

预期：输出 `allow: N / deny: 0`（脚本覆盖 masked/encrypted/aggregate 三类，aggregate 应用保留授权基线）。

### 步骤 4：核对四类输出模式真实调用

```bash
docker exec nocobase-8196-postgres-1 psql -U nocobase -d nocobase -c \
  "SELECT effective_output_mode, decision_result, count(*) FROM security_policy_decision_logs \
   WHERE requested_at >= current_date GROUP BY 1, 2 ORDER BY 1, 2"
```

预期：今天存在 masked/encrypted/aggregate 三类的 `allow` 记录（明细输出来自基线 API）。

### 步骤 5：按应用核对调用分布

```bash
docker exec nocobase-8196-postgres-1 psql -U nocobase -d nocobase -c \
  "SELECT s.subject_name, count(*) FROM security_policy_decision_logs l \
   JOIN security_access_subjects s ON s.id = l.subject_id \
   WHERE l.requested_at >= current_date GROUP BY 1 ORDER BY 2 DESC LIMIT 10"
```

预期：网上电网、智能供服、数据传输、全链路监控等客户应用均有真实调用。

### 步骤 6：页面核对

1. 打开首页，确认"访问调用"计数来自真实决策日志（页面标注"来自真实决策日志"）。
2. 打开调用与决策日志页（组件配置/日志），按应用筛选，确认记录可查。
